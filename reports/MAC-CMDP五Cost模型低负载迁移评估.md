# MAC-CMDP五Cost模型低负载迁移评估

## 1. 评估目的与口径

本实验不重新训练模型，固定使用高负载实验的 `step_100.pt`，在用户调整后的较低业务并发下，以评估 seed 66 对比 Default EDCA 与 Final 贪心策略。两种策略使用相同拓扑、外生业务随机种子和 20 s 测量窗口。

新业务数量为：VoIP UL/DL 20/10，Gaming UL/DL 30/20，BV3 UL 10，HTTP-BE DL 10，FTP-BE UL 6，HTTP-BK DL 10，FTP-BK UL 10，共126条MAC业务流。模型训练时的网络结构、动作空间、Reward/Cost和checkpoint均未修改。

| VO及时率 | 53.79% | 62.49% | +16.17% |
| VI及时率 | 29.90% | 39.33% | +31.52% |
| VO需求满足度 | 96.96% | 98.55% | +1.64% |

## 3. 分方向MAC表现

| 方向 | p95 Default→Final | 最终失败率 Default→Final | 重传率 Default→Final |
|---|---:|---:|---:|
| VO UL | 118.10→84.83 ms | 6.16%→2.96% | 71.04%→65.86% |
| VO DL | 39.91→37.94 ms | 0.87%→0.16% | 37.25%→30.88% |
| VI UL | 472.17→444.10 ms | 19.37%→8.46% | 48.63%→49.72% |
| VI DL | 117.22→104.19 ms | 5.01%→5.01% | 8.24%→7.68% |

与此前高负载评估不同，本次低负载下 Final 没有再造成 VI DL 尾时延退化；四个高优先级方向的p95均下降。VI UL重传率略升约1.1个百分点，但其吞吐、p95和最终失败率同时改善，不能把该重传变化单独解释为性能退化。

图中的重传率定义为“逐MPDU重传次数/传输尝试次数”。当前summary trace不能可靠区分碰撞、信道误码及其他未确认原因，因此该指标不称为碰撞率。

## 4. 五Cost检查

| Cost | 预算 | Default | Final | Final是否满足预算 |
|---|---:|---:|---:|---|
| VO DL | 0.40 | 0.31 | 0.27 | 是 |
| VO UL | 0.61 | 0.53 | 0.45 | 是 |
| VI DL | 0.49 | 0.37 | 0.35 | 是 |
| VI UL | 0.79 | 0.71 | 0.61 | 是 |
| Starvation | 0.90 | 1.00 | 1.00 | 否 |

四个方向QoS Cost均降低并满足预算；Starvation Cost几乎不变且仍违反预算，说明模型对高优先级服务的迁移有效，但低优先级保护仍未解决。

## 5. 结论

在这一较低负载、单个评估seed下，高负载训练得到的Final策略整体优于Default：四方向p95均未退化，VO/VI及时率、有效吞吐、最终失败率和公平性总体改善。该结果表明此前VI DL严重退化与高负载工作区间有关，并非模型在所有负载下都会损害VI DL。

但本结果只有seed 66，不能替代多seed统计；BE/BK仍严重饥饿，尤其BK的绝对成功业务量极少，低基数百分比不能作为已经解决低优先级服务问题的证据。
